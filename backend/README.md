# backend

FastAPI servisi ve öneri motoru. Faz 1'de (9 Kasım 2026) başlar.

Planlanan modüller:

- `catalog` — parça, sanatçı, kimlik eşleme, zenginleştirme hattı
- `graph` — benzerlik grafiği, tembel genişleme, paylaşılan önbellek
- `profile` — oy olay kaydı, normalizasyon, çok modlu profil
- `recommend` — PPR aday skoru, gerekçe üretimi, MMR, bandit slot dağılımı
- `releases` — takip listesi, yayın tespiti, haftalık Taze listesi
- `adapters` — Spotify, Apple Music ve bağlantısız mod adaptörleri
